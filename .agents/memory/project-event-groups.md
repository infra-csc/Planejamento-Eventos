---
name: Grupos de projetos
description: Intenção do usuário para organização de projetos por nomes livres de eventos.
---

O usuário pediu: “Escrever o nome do evento e com isso criar um grupo; nas próximas vezes selecionar este grupo ou criar outro.”

Projetos podem ficar como Padrão ou pertencer a um grupo reutilizável com nome livre. Isso organiza a biblioteca, sem exigir um evento cadastrado, incluir itens automaticamente em OS ou restringir em quais eventos o projeto pode ser pedido.

**Why:** a resposta do usuário substituiu a proposta de vínculo exclusivo com um evento por grupos criados a partir de nomes digitados.

**How to apply:** manter o grupo separado da categoria do projeto. Preservar grupos vazios para reutilização futura e não reinterpretar seus nomes como relações com eventos do sistema. Alterar só essa organização não deve criar uma versão nova da lista de peças.
