---
name: Standalone tent accessories
description: Preserve independent accessory orders in specialized OS exports.
---

Keep independently ordered tent accessories separate from the parts allocated to tent projects.

**Why:** the specialized structure export excluded tent-coded loose pieces on the assumption that the tent table already covered them. The OS calculation was correct, but that table only described project parts. Assigning loose accessories to an arbitrary kit instead would invent a relationship and risk double counting.

**How to apply:** show separately requested closures, gutters and other tent parts with their own quantity and destination in the separate-materials block. An exclusion is safe only when that actual quantity is represented elsewhere, not merely because its catalogue code belongs to a tent kit.
